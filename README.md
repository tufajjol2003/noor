# Noor

Noor — Islamic app with Bengali and English UI. Prayer times with countdown, full Quran (114 surahs), duas, Qibla compass, Zakat calculator, Hijri date. Version 2.0, native Android app (Android 7.0+).

Download the latest APK from the [Releases](https://github.com/tufajjol2003/noor-apk/releases) page.
